# cybersecurity-labs
My personal cybersecurity learning environment using virtual machines to practice network security , tools , exploitation and simulating attacks in an isolated environment



## Lab Environment
- Kali Linux (Attacker)
- Windows 7 (Vulnerable Target)
- Metasploitable 2 (Vulnerable Target)

## Tools Used
- Nmap
- Metasploit Framework
- Wireshark
- Meterpreter
- Basic OSINT tools

## Topics Covered
- Network scanning and enumeration
- Exploitation techniques (EternalBlue, etc.)
- Traffic analysis
- Vulnerability research
